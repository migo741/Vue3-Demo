# Vue3 中高级进阶练习计划

> 目标：从初中级 → 中高级（对齐大厂 Vue 开发要求）
> 预计周期：2 周（每天 2-3 小时）
> 原则：一题顶百题，每道题都是经典场景，覆盖真实业务开发

## 练习结构

```
learn/
├── 01-reactivity-deep/        # 响应式原理深入
├── 02-composables/             # 组合式函数进阶
├── 03-component-patterns/      # 组件设计模式
├── 04-router-advanced/         # 路由进阶
├── 05-state-management/        # 状态管理
├── 06-performance/             # 性能优化
├── 07-typescript-vue/          # TypeScript + Vue
├── 08-render-pattern/          # 渲染模式（JSX/render/HOC）
├── 09-directive-plugin/        # 自定义指令与插件
├── 10-testing/                 # 组件测试
├── 11-real-world/              # 综合实战
```

## 难度标记

- 🟢 中级（巩固基础，快速完成）
- 🟡 中高级（需要思考设计）
- 🔴 高级（大厂面试/实战级别）

## 每道题的结构

每道练习题包含：

- `README.md` — 题目描述、要求、提示
- `index.vue` 或相关文件 — 起始模板（部分题目提供）
- `answer/` — 参考答案（建议先独立完成再对照）

## 如何验证

- 每道题都有明确的验收标准
- 部分题目附带单元测试
- 综合实战题有完整的功能验收清单
